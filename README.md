**Atividade do módulo - Azure Cognitive Search: Utilizando AI Search para indexação e consulta de Dados**

**Curso Decola Tech 2025 - DIO**

Durante esta atividade, utilizei os serviços do Azure AI Services integrados com o AzureTech para realizar a análise de dados de feedback de clientes. O objetivo foi testar a capacidade de busca e interpretação de informações específicas dentro de um índice de documentos, através do Explorador de Pesquisa do Azure.

No exercício, foi realizado uma consulta JSON no AzureTech, filtrando informações de localização com o critério: "locations:'Chicago'". O sistema retornou dados estruturados contendo feedbacks variados sobre estabelecimentos localizados na cidade de Chicago.

A ferramenta identificou diferentes tipos de sentimentos e temas nas avaliações, permitindo compreender a satisfação e as reclamações dos clientes. O Azure AI Services, em conjunto com o AzureTech, demonstrou eficácia na organização e na filtragem de dados, facilitando a tomada de decisão baseada em informações concretas.

Essa prática evidenciou como a análise automatizada de dados pode otimizar a gestão de feedbacks e aperfeiçoar serviços de atendimento ao cliente, além de oferecer insights valiosos para a melhoria contínua de produtos e serviços.
