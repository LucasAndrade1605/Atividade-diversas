O objetivo do projeto é realizar o backend de listas de games personalizadas.

**END-POINTS**

GET - GetAllMin -  Retorna todos os jogos com apenas os atributos minimos, para lista de jogos

GET - GetIdMax - Retorna um jogo com todos os atributo

GET - GetAllList -  Retorna todas as listas de jogos

GET - GetGameByList - Retorna todos os jogos(GetAllMin) de uma lista.

POST - AtualizaLista - Atualiza a posicao dos jogos na lista.
